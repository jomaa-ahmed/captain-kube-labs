# Lamps on every dock

Some things must run on **every** dock: a lamp, a log collector, a network agent. That's a **DaemonSet**.
And some pods are started by the kubelet alone, from a file: **static pods**.

Lessons: [2.9 DaemonSets](https://captains-academy.site/course/kubernetes/lesson/2.9) · [2.10 Static pods](https://captains-academy.site/course/kubernetes/lesson/2.10)
