# Hand over

In `/root/handover`, the logbook belongs to another team from today. Terraform must let go of it, and the
file must stay exactly where it is. Then the other team asks for a debug log.

Lessons: [9.4 Letting go with removed](https://captains-academy.site/course/terraform/lesson/9.4) · [9.5 Verbose logging](https://captains-academy.site/course/terraform/lesson/9.5)
